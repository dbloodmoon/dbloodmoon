## What I bring

- **API design** — RESTful endpoints with FastAPI, automatic OpenAPI documentation at `/docs`, consistent error handling.
- **Data layer** — SQLAlchemy 2.x models that run unchanged on SQLite (dev) and PostgreSQL (production), Pydantic v2 validation at the boundary.
- **Auth** — stateless JWT with bcrypt hashing, per-user data isolation enforced on every query.
- **Testing & CI** — pytest suites with dependency overrides, wired into GitHub Actions so every push is verified.
- **Product sense** — accessibility (WCAG 2.1 AA), i18n and theming done right, not as an afterthought.
